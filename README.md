# 🎓 강의용 듀얼 프리젠터 (DualLecturePresenter for macOS)

강의 진행 시 **강사용(어노테이션, 비밀 메모, 답안 포함) PDF**와 **학생용(클린 버전) PDF**를 동시에 관리하며, 스크롤과 액션을 실시간 동기화하는 맥(macOS) 전용 프리젠터 앱입니다.

학생용 화면은 **독립된 윈도우**로 분리되어 있어, Zoom, Google Meet, Microsoft Teams 등 화상회의 프로그램에서 **학생용 윈도우만 단독으로 화면 공유**할 수 있습니다.

---

## ✨ 핵심 기능

1. **독립 윈도우 듀얼 프레젠테이션 (온라인 화면 공유 최적화)**
   - **강사용 윈도우**: 강의 진행 컨트롤, 타이머, 실시간 학생 화면 모니터링, 슬라이드 썸네일, 강사 전용 메모 표시
   - **학생용 윈도우**: 온라인 공유용 클린 화면 (불필요한 컨트롤 및 비밀 메모 완전 차단)
   - 듀얼 모니터 / 프로젝터 연결 시 자동으로 2번 디스플레이에 학생용 창을 배치합니다.

2. **완벽한 스크롤 & 페이지 동기화**
   - **슬라이드 모드 (1장씩)**: 키보드 방향키(`←`, `→`), 스페이스바, 프리젠터 리모컨으로 페이지 전환 시 학생 화면 동기화
   - **연속 스크롤 모드**: 트랙패드 휠 스크롤 시 문서 비율에 맞춰 학생 화면도 부드럽게 픽셀 단위로 실시간 동기화

3. **화면 비율(Aspect Ratio) 일치 및 레터박스 방지 (Zoom 공유 최적화)**
   - 두 화면의 가로세로 비율이 다르면 온라인 화면 공유(Zoom 등) 시 빈 검은 여백(레터박스)이 생기거나, 연속 스크롤 시 화면에 보이는 범위가 달라질 수 있습니다.
   - **4가지 비율 모드 지원**:
     - **PDF 원본 비율 (`PDF Native`)**: 문서 첫 페이지의 실제 가로세로 비율로 학생 창을 자동 리사이징 및 고정
     - **강사 뷰 비율 복제 (`Match Instructor`)**: 강사가 보고 있는 작업 창 뷰포트 크기와 학생 창의 비율을 실시간 1:1로 일치
     - **16:9 와이드 & 4:3 표준**: 일반적인 프로젝터 및 디스플레이 표준 비율로 1클릭 맞춤
     - **자유 조절**: 창 모서리를 드래그하여 임의 크기로 조절 가능
   - `NSWindow.contentAspectRatio` 제약 조건을 적용하여 창 크기를 조절해도 지정한 비율이 흐트러지지 않습니다.

4. **실시간 레이저 포인터, 필기, 형광펜 & 텍스트 타이핑 동기화**
   - **레이저 포인터 (`⌘+L` / `L`)**: 강사용 화면에서 마우스를 움직이면 학생 화면의 해당 위치에 밝은 레드 레이저 포인터가 실시간 투영됩니다. **레이저 포인터를 사용하는 중에도 2손가락 트랙패드/마우스 휠 스크롤이 원활하게 동작**합니다.
   - **펜 필기 (`⌘+D` / `P`)**: 슬라이드 위에 즉석에서 원이나 밑줄을 그으면 학생 화면에도 동기화되어 나타납니다.
   - **형광펜 (하일라이터, `⌘+H` / `H`)**: 굵고 투명한 노란색 스트로크로 텍스트나 도표를 가리지 않고 부드럽게 강조합니다.
   - **텍스트 타이핑 (`⌘+T` / `T`)**: 슬라이드 위 원하는 위치를 클릭하여 즉석에서 텍스트 노트를 입력할 수 있으며, 입력 즉시 학생 화면에 동기화 표시됩니다.
   - **지우개 (`⌘+E` / `E`)**: 마우스로 필기 선이나 텍스트를 드래그하여 직관적으로 지울 수 있습니다. (페이지별/전체 한 번에 지우기 지원)

5. **비밀 엿보기 모드 (Sync Pause)**
   - 학생들은 현재 슬라이드를 보고 있는 동안, 강사는 동기화를 일시 정지하고 다음 슬라이드나 답안 메모를 미리 확인할 수 있습니다.
   - `다시 동기화`를 누르면 학생 화면이 강사의 현재 화면으로 즉시 따라옵니다.

6. **학생 화면 암전 (Blackout / `B`)**
   - 강사에게 주의를 집중시키거나 잠시 화면을 가려야 할 때 학생 화면을 블랙아웃 처리합니다. (강사용 화면은 정상 유지)

7. **강사용 실시간 학생 화면 미니 모니터**
   - 강사용 대시보드 우측에 학생들이 보고 있는 화면이 미니 프리뷰로 상시 표시되어 공유 상태를 100% 확신할 수 있습니다.

8. **자동 파일 페어링 (Auto-Pairing)**
   - `lecture_instructor.pdf`를 열면 같은 폴더에 있는 `lecture_student.pdf`를 자동으로 감지하여 함께 로드합니다.
   - 파일이 하나뿐인 경우 `[강사용 PDF와 동일본으로 사용]` 버튼으로 즉시 시작할 수도 있습니다.

## ⌨️ 단축키 안내

> [!NOTE]
> `Space`, `←`, `→`, `PageUp`, `PageDown` 및 도구 전환 키(`B`, `L`, `P`, `H`, `T`, `E`)는 시스템 전역 이벤트 모니터(`NSEvent`)를 통해 `PDFView`의 포커스 상태와 관계없이 언제나 즉시 반응합니다. (단, 텍스트 타이핑 입력 중에는 방해 없이 일반 글자 입력으로 동작합니다.)

| 기능 | 단축키 | 설명 |
| :--- | :--- | :--- |
| **다음 슬라이드** | `Space` 또는 `→` (또는 `PageDown`) | 다음 페이지로 동기화 이동 (프리젠터 리모컨 호환) |
| **이전 슬라이드** | `Shift+Space` 또는 `←` (또는 `PageUp`) | 이전 페이지로 동기화 이동 |
| **화면 암전 (Blackout)** | `B` | 학생 화면만 검은색으로 가리기 (토글) |
| **기본 포인터** | `⌘ + 0` | 일반 마우스 커서 모드 |
| **레이저 포인터** | `L` 또는 `⌘ + L` | 마우스 커서 위치에 레이저 포인터 투영 (스크롤 가능) |
| **펜 필기 모드** | `P` 또는 `⌘ + D` | 슬라이드 위 자유 필기 |
| **형광펜 (하일라이터)** | `H` 또는 `⌘ + H` | 반투명 굵은 노란색 강조 |
| **텍스트 타이핑** | `T` 또는 `⌘ + T` | 슬라이드 클릭 후 텍스트 입력 (Enter 완료) |
| **지우개 모드** | `E` 또는 `⌘ + E` | 필기 선 및 텍스트 드래그 삭제 |
| **현재 페이지 필기 삭제** | `⌘ + K` | 현재 슬라이드의 모든 필기/텍스트 즉시 삭제 |
| **비밀 엿보기 (동기화 토글)** | `⌘ + S` | 학생 화면 고정 후 강사만 자유 스크롤 |
| **학생용 윈도우 토글** | `⌘ + ⇧ + P` | 학생용 창 열기/닫기 |

## 🚀 실행 및 설치 방법

### 1. 즉시 실행
Finder에서 빌드된 앱 번들을 바로 실행할 수 있습니다:
```bash
open /Users/codex/prj/download-bible-project/DualLecturePresenter/DualLecturePresenter.app
```

### 2. Mac 응용 프로그램(/Applications)에 설치
```bash
cd /Users/codex/prj/download-bible-project/DualLecturePresenter
./install_to_applications.sh
```
설치 후 Spotlight (`⌘ + Space`)에서 **DualLecturePresenter** 또는 **강의용 듀얼 프리젠터**를 검색하여 실행할 수 있습니다.

## 💻 프로젝트 기술 스택
- **Language**: Swift 6
- **UI Framework**: SwiftUI + AppKit
- **Document Engine**: Apple PDFKit (PDFView, PDFDocument)
- **Minimum macOS**: macOS 13.0 (macOS Sequoia 15.x 완벽 대응)
